# Zuil

Static site for the Zuil table lamp: a hand-cast mineral base, three pine dowels and a 3D-printed diffuser.

- `index.html`, `css/zuil.css`: the page
- `assets/`: images (lamp renders, story close-ups, making-of photos)
- `tools/`: the list of source images and the script that downloads and resizes them (run by the "Fetch assets" GitHub Action)

Published with GitHub Pages from the `main` branch.
